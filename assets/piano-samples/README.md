# Piano samples

Salamander Grand Piano V3 by Alexander Holm (a Yamaha C5 grand), licensed under
[Creative Commons Attribution 3.0](https://creativecommons.org/licenses/by/3.0/).
These are the 30-note, one-layer MP3 set (every minor third, A0 to C8) that Tone.js publishes at
https://tonejs.github.io/audio/salamander/ and that `tambien/Piano` (MIT) is built on.

`virtual-studio/sound.js` plays them as the Virtual Space's playable grand.
