# The removed Vienna "behind-wall annex" (19 October 2026), recovered

The first, mistaken build of the Vienna Piano Stage (19 Oct 2026, 13:40–13:57 UTC, worktree virtual-space-vienna,
before commit 75b1161) put the grand and its lift in an annex beyond the studio's Vienna-side wall, reached through an
opening cut in that wall. It was replaced the same afternoon by the lift at the grand's original place (75b1161:
"There is no second piano, no annex"). It was never committed; these files are its source as written then, recovered
from the Claude session transcript 841bf26f-38c0-44a7-8e38-406c19f257a3. Reference only: not loaded by any page.
